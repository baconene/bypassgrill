# Homepage dish cutouts

Drop transparent-background images here and the homepage picks them up automatically
(no code change, no rebuild). Use exactly these file names, `.webp` preferred, `.png` also works:

| Dish                     | File name                       |
| ------------------------ | ------------------------------- |
| Pork Monster Ribs (hero) | `pork-monster-ribs.webp`        |
| Jamaican Chicken Jerk    | `chicken-jerk.webp`             |
| Grilled Pork Liempo      | `grilled-pork-liempo.webp`      |
| Rustic Chicken Skewers   | `rustic-chicken-skewers.webp`   |

Recommended: about 1200 × 1200 px, the dish centred with some empty space around it, under 250 KB.

Without a cutout, the homepage uses the dish's photo uploaded in the POS (shown on a round plate),
and without that, a placeholder plate.
